# Taskmark website

Public Taskmark product site (docs and marketing). Shares the UI component stack
and visual language with `taskmark-frontend`.

## Scripts

```bash
npm install
npm run dev
npm run build
npm run lint
```

## Stack

- Next.js 16 / React 19
- Tailwind CSS v4
- shadcn base-nova (`@base-ui/react`)
- Same theme tokens and fonts as the board UI
